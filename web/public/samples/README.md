# Test samples

Labeled 10-second WAVs used by the Detect tab "Try IRRI research samples" buttons.

| File | Expected class | Origin |
|------|----------------|--------|
| `rice_weevil.wav` | rice_weevil | IRRI Rice Acoustic Sensor (`S_oryzae`) |
| `lesser_grain_borer.wav` | lesser_grain_borer | IRRI Rice Acoustic Sensor (`R_dominica`) |
| `red_flour_beetle.wav` | red_flour_beetle | IRRI Rice Acoustic Sensor (`T_castaneum`) |
| `clean.wav` | clean | Ambient / no-pest reference clip |

Pest clips are from the open dataset published with Balingbing et al. (IRRI / University of Kassel):

https://github.com/cbalingbing/Rice-Acoustic-Sensor
