\subsection{Strong CNN training recipe}
\begin{itemize}[leftmargin=*]
  \item SpecAugment (freq $\le 16\times2$, time $\le 24\times2$)
  \item Cosine LR from $10^{-3}$
  \item Label smoothing $0.05$
  \item Balanced class weights; weevil $\times 1.15$; borer $\times 1.25$
  \item $\le 60$ epochs, early stopping
  \item Optional waveform aug: pitch, pink noise SNR, time stretch
\end{itemize}
